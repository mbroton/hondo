# Security policy

## Report a vulnerability

Report vulnerabilities through GitHub private vulnerability reporting: open
the **Security** tab of this repository and select **Report a vulnerability**.
Do not open a public issue.

Tell us what is affected, how to reproduce the problem, and what an attacker
can do with it. We reply as soon as we can and tell you when a fix is
released.

## Supported versions

We fix security problems in the latest release.
